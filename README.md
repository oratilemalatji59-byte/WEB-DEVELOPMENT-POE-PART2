# WEB-DEVELOPMENT-POE-PART2
I am creating GLAZE LIPGLOSS

GLAZE A lip gloss brand website built.

Concept

GLAZE sells lip gloss with added color —  dyes, mica, pigment of any kind. The formulas are built entirely around shine and reflectivity, so each product is named for how it behaves under light (Glass, Chrome, Vinyl, Satin, Frost, Wet) rather than what shade it wears. The site follows the same idea: no color anywhere in the design.

Pages

File	Description
glaze.html and CSS	Home page — hero intro, brand philosophy, and a preview of the finishes
about.html and CSS	Brand story — the idea behind a colorless gloss, what's not in the formula, what is
shop.html and CSS	Full list of all six finishes with prices and links to product details
product.html and CSS Product detail page (currently set up for Finish No. 01, Glass)
order.html and CSS	Order form to place a new order, plus a form to track an existing order
contact.html and CSS	Contact form (name, email, reason, message) plus email and mailing address
All pages share the same header navigation and footer. • The hook: every formula is completely pigment-free — no dyes, no mica, no colorant of any kind. Instead of selling shades, GLAZE sells finishes — six of them (Glass, Vinyl, Chrome, Satin, Frost, Wet), each named for how it reflects light rather than what color it wears. • The site: a 6-page static website (Home, About, Shop, Product, Order, Contact) built in pure HTML in plain browser-default styling, matching the brand’s “no color” philosophy even in the code itself. • Status: all pages are linked together with working navigation. The order and contact forms are real HTML and CSS and the product page currently covers one finish (Glass) as a template for the rest.
